# fake-news-detection

This project detects whether a news article is fake or real using Machine Learning and NLP techniques.



📰 Fake News Detection System



📌 Project Overview

This project is a Machine Learning + Flask web application that detects whether a news article is REAL or FAKE using Natural Language Processing (NLP) techniques.





🚀 Features

\- Detects fake or real news

\- NLP text preprocessing

\- TF-IDF vectorization

\- Machine learning model prediction

\- Web interface using Flask

\- Stores prediction history







🛠️ Technologies Used

\- Python

\- Flask

\- Scikit-learn

\- Pandas

\- NumPy

\- HTML, CSS, JavaScript
